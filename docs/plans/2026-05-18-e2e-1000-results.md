# E2E 1000-row Augmented Benchmark Results

## Dataset
- Existing benchmark: `data/expanded_hard_binary_qa_500.csv`
- Additional non-overlapping benchmark: `data/expanded_hard_binary_qa_extra500.csv`
- Combined benchmark: `data/expanded_hard_binary_qa_1000.csv`
- Composition: 1000 rows total
  - `voicephishing`: 500
  - `bank_call`: 500
  - `irrelevant`: excluded

This is a 1000-row augmented benchmark derived from the 67-row hard binary seed set. It should be described as an augmented robustness check, not as 1000 fully independent human-authored scenarios.

## Retrieval-threshold results

| Pipeline | 1000 rows | Voicephishing | Bank call |
| --- | ---: | ---: | ---: |
| Original Naive RAG | **0.8210** | 0.7040 | 0.9380 |
| Masked Naive RAG | **0.5410** | 0.1440 | 0.9380 |
| Masked Advanced RAG | **0.9110** | 0.8840 | 0.9380 |

## E2E results

| Pipeline | 1000 rows | Voicephishing | Bank call |
| --- | ---: | ---: | ---: |
| Original RAG | 894/1000 = **0.8940** | 450/500 = **0.9000** | 444/500 = **0.8880** |
| Masked RAG | 513/1000 = **0.5130** | 103/500 = **0.2060** | 410/500 = **0.8200** |
| Masked Advanced RAG | 953/1000 = **0.9530** | 472/500 = **0.9440** | 481/500 = **0.9620** |

## Comparison across scales

| Pipeline | 335 e2e | 500 e2e | 1000 e2e |
| --- | ---: | ---: | ---: |
| Original RAG | 0.8955 | 0.8920 | **0.8940** |
| Masked RAG | 0.5134 | 0.5120 | **0.5130** |
| Masked Advanced RAG | 0.9522 | 0.9520 | **0.9530** |

The trend remains stable after expanding from 335 to 500 and then to 1000 augmented rows.

## Technical note
Original and Masked e2e runs used `gpt-4o-mini`. During the additional Advanced RAG run, the `gpt-4o-mini` batch queue became stuck at cancellation after 199/200 requests, so the remaining Advanced-pattern requests were completed with `gpt-4.1-mini` as a fallback. The final Advanced score should be treated as a robustness/checkpoint result unless rerun under one identical model is required.
