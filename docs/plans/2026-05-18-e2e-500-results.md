# E2E 500-row Results

## Benchmark
- Dataset: `data/expanded_hard_binary_qa_500.csv`
- Composition: 500 rows total
  - `voicephishing`: 250
  - `bank_call`: 250
  - `irrelevant`: excluded
- Purpose: verify whether the 335-row expanded hard benchmark trend remains stable under additional transcript-style augmentation.

## E2E pipeline results

| Pipeline | Evaluation | Overall | Voicephishing | Bank call |
| --- | --- | ---: | ---: | ---: |
| Original RAG | gpt-4o-mini e2e, identifier-filtered flow | 446/500 = **0.8920** | 225/250 = **0.9000** | 221/250 = **0.8840** |
| Masked RAG | gpt-4o-mini e2e, identifier-filtered flow | 256/500 = **0.5120** | 54/250 = **0.2160** | 202/250 = **0.8080** |
| Masked Advanced RAG | gpt-4o-mini e2e + advanced pattern reranking + normal-resolution guard | 476/500 = **0.9520** | 236/250 = **0.9440** | 240/250 = **0.9600** |

## Note on Advanced RAG guard
A pure advanced-pattern prompt without the normal-resolution guard reached 384/500 = **0.7680** overall:

- Voicephishing: 250/250 = **1.0000**
- Bank call: 134/250 = **0.5360**

This over-predicts `yes` for normal bank calls. The final Advanced RAG result therefore uses the same normal-resolution guard as the 335-row experiment: official-app / representative-number / branch-visit / internal-review style normal resolution is routed to `no` when there is no explicit scam-action signal.

## Comparison with 335-row E2E result

| Pipeline | 335 rows | 500 rows |
| --- | ---: | ---: |
| Original RAG | 0.8955 | **0.8920** |
| Masked RAG | 0.5134 | **0.5120** |
| Masked Advanced RAG | 0.9522 | **0.9520** |

The 500-row e2e result preserves the 335-row trend almost exactly.
